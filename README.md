# Personal Portfolio

> https://advaitmannepalli.github.io/

My personal portfolio site — built with plain HTML, CSS, and JS (no framework, no build step).

## Sections

- Home
- About
- Interests
- Education
- Experience
- Projects
- Skills
- Contact

## Running locally

No build step needed — just serve the directory:

```
python3 -m http.server
```

Then open `http://localhost:8000`.
