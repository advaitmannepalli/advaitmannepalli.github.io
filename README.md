## About me

I'm Advait Mannepalli, a Computer Science student at The University of Texas at Austin. My interests include systems programming, machine learning, quantitative finance, and information retrieval.

Through CS439 and the Pintos teaching operating system, I've been enjoying working on multithreaded problems, synchronization, scheduling, and understanding how the kernel works. I've also shipped production websites end-to-end, from frontend UI and backend APIs to hosting, DNS, and SEO.

## Featured projects

- **Pintos Lab 1:** Operating system work in C covering thread sleeping, priority scheduling, synchronization, and nested priority donation. The portfolio includes implementation details; source code is not public due to course rules.
- **[Hybrid Search Engine](https://github.com/advaitmannepalli/hybrid-search):** A search project built with Python, FastAPI, and OpenSearch.
- **[Portfolio Risk & Monte Carlo Simulator](https://github.com/advaitmannepalli/stock_portfolio_backtester):** A portfolio backtesting and simulation project using Python, pandas, NumPy, and yfinance.
- **[Minigrep](https://github.com/advaitmannepalli/minigrep):** A Rust project completed through The Rust Book.
